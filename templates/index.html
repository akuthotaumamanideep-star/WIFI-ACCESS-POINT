DAA Viva Voce & Algorithmic Theory Guide

1. Problem Formulation: Maximum Coverage Problem

Let U = {r₁, r₂, ..., rₙ} be the universe of classrooms situated at 2D coordinates. Let C = {c₁, c₂, ..., c_m} be the set of possible candidate Access Point positions. For any candidate c ∈ C, its coverage set is defined using Euclidean distance:

Cover(c) = { r ∈ U  |  √((x_c - x_r)² + (y_c - y_r)²) ≤ R }

Optimization Goal: Select a subset S ⊆ C such that |S| ≤ K and |⋃_{c ∈ S} Cover(c)| is maximized.

2. Why Greedy Approach?

  • NP-Hardness: The Maximum Coverage problem is known to be NP-hard. Finding the exact global optimum would require checking all 𝒞(m, K) = m! / (K!(m-K)!) combinations, which is computationally infeasible for realistic layouts.
  • Submodular Property: The coverage function f(S) = |⋃_{c ∈ S} Cover(c)| is monotone and submodular (exhibits diminishing marginal returns).
  • Theoretical Guarantee: A famous theorem by Nemhauser, Wolsey & Fisher (1978) proves that the Greedy heuristic guarantees an approximation ratio of at least: 1 − 1/e ≈ 63.2% of the optimal solution!

Time Complexity Derivation

Step / Operation Complexity Explanation
1. Candidate Generation O(M) Grid sampling and corridor midpoint generation (M candidate locations).
2. Precomputing Coverage Sets O(M · N) For each of M candidates, measure Euclidean distance to N classrooms.
3. Greedy Selection Loop O(K · M · N) K iterations. In each iteration, evaluate remaining candidates to find max marginal gain.
Total Worst-Case Time O(K · M · N) Highly efficient polynomial time! With N=50, M=100, K=5, it takes milliseconds.

Space Complexity Derivation

Total Space Complexity: O(M · N + M + N) = O(M · N)

  • Storing coverage sets for M candidate APs over N classrooms: O(M · N)
  • Set of covered classrooms and selected APs: O(N + K)
Q1. What is the Greedy Choice Property used in this project?
At every iteration, the algorithm makes the locally optimal choice: it selects the candidate AP that covers the largest number of currently uncovered classrooms (maximum marginal gain), without reconsidering past decisions.
Q2. Is the solution always globally optimal?
Not necessarily globally optimal, because Maximum Coverage is NP-hard. However, it is mathematically proven to be within (1 - 1/e) ≈ 63.2% of the absolute optimal coverage, and in practical network layouts, greedy typically reaches 90% - 98% of the true optimum.
Q3. Why not use Dynamic Programming or Brute Force?
Brute force tests all C(M, K) combinations, which has exponential complexity O(M^K). Dynamic programming requires optimal substructure and overlapping subproblems without submodular interference; for 2D spatial geometric set coverage, DP states explode into exponential dimensions.
Q4. How are candidate AP locations generated?
We combine three practical engineering strategies: (1) A uniform bounding box lattice/grid over the floor plan, (2) Direct classroom ceiling positions, and (3) Corridor midpoints between nearby classroom pairs.
Q5. What distance metric is used and why?
2D Euclidean distance √((x₂-x₁)² + (y₂-y₁)²) is used to model free-space path loss (FSPL) and omnidirectional antenna transmission patterns in an open academic floor plan.
Q6. What happens if all classrooms are covered before using all available APs?
The algorithm terminates early! If |covered_classrooms| == N or the best marginal gain is 0, no additional APs are deployed, preventing budget waste.
Q7. What is submodularity and why does it matter here?
A set function f is submodular if adding an element to a smaller set yields at least as much increase as adding it to a larger set (diminishing marginal returns). Because coverage is submodular, the greedy algorithm is guaranteed to approximate the optimum within (1 - 1/e). 
Algorithm GreedyMaxCoverage(U, C, R, K):
  // Inputs: U = Classrooms, C = Candidates, R = Radius, K = Max APs
  // Output: S = Selected AP locations

  for each candidate c ∈ C do:
      Cover[c] ← { r ∈ U | EuclideanDist(c, r) ≤ R }
  end for

  Covered ← ∅
  S ← ∅

  while |S| < K and |Covered| < |U| do:
      bestCandidate ← null
      maxGain ← -1

      for each c ∈ (C \ S) do:
          marginalGain ← |Cover[c] \ Covered|
          if marginalGain > maxGain then:
              maxGain ← marginalGain
              bestCandidate ← c
          end if
      end for

      if maxGain ≤ 0 then:
          break   // No candidate can cover any more rooms
      end if

      S ← S ∪ {bestCandidate}
      Covered ← Covered ∪ Cover[bestCandidate]
  end while

  return S, Covered
